# MedClinic

Навчальний Django-проєкт для онлайн-запису пацієнтів до лікарів.

Інтерфейс адаптований для комп'ютерів і телефонів та використовує однакові компактні елементи форм у всіх кабінетах.
Поля завантаження показують поточний файл, його видалення та вибір заміни в одному зрозумілому блоці.
Кнопки візуально розрізняють основні, другорядні, підтверджувальні та небезпечні дії й мають помітні стани наведення, натискання та клавіатурного фокусу.

## Можливості

- вхід пацієнта через Google;
- створення кабінету для пацієнта, якого раніше записав лікар: пошук незареєстрованих записів за телефоном і обов’язкове прив’язування через Google;
- приховування email у профілях і медичних картках пацієнтів та лікарів; пошта Google використовується лише технічно для авторизації;
- завантаження пацієнтом власного фото профілю, яке також бачить лікар у списку та картці пацієнта;
- обов'язкове заповнення імені, прізвища та віку пацієнта перед записом на прийом із помітним нагадуванням у кабінеті;
- пошук пацієнтів лікарем за ім'ям, прізвищем або номером телефону;
- показ віку пацієнта у списку пацієнтів, прийомах і детальній інформації для лікаря;
- вхід лікаря й адміністратора за ім'ям користувача та паролем;
- створення лікарів, послуг і графіків адміністратором;
- згортання та розгортання довгого списку послуг у картці лікаря;
- заявки пацієнтів із вибором лікаря, послуги, дати та часу;
- список прийомів лікаря, згрупований за датами з українськими назвами днів тижня й відсортований за часом, із переходом до деталей або картки пацієнта;
- кольорове розрізнення нових заявок, підтверджених, завершених, скасованих і відхилених прийомів у списку лікаря;
- додавання декількох фотографій або медичних знімків до заявки пацієнта;
- окрема детальна сторінка заявки для лікаря з фотографіями одразу під інформацією про прийом і правою вертикальною панеллю записів на вибраний день;
- вибір тривалості прийому в хвилинах самим лікарем під час підтвердження заявки;
- тривалість прийому в хвилинах, кратна тривалості слота конкретного дня графіка;
- обідня перерва в графіку лікаря з вибором часу початку та тривалості;
- прямий запис лікарем нового чи зареєстрованого пацієнта;
- перевірка всіх зайнятих слотів і заборона запису в минулому;
- скасування та відновлення записів;
- зрозуміле відновлення скасованого запису без відокремлення дії від самого прийому;
- автоматичне завершення прийому після закінчення його часу;
- картки пацієнтів, історія прийомів і нотатки лікаря;
- зелений блок активного прийому в кабінеті лікаря;
- розширені медичні записи в картці пацієнта з типом запису, детальним описом, рекомендаціями та кількома фотографіями;
- показ лікування й рекомендацій лікаря в особистому кабінеті пацієнта;
- завантаження фотографій лікарів із пристрою.
- короткий текст «Про лікаря», який лікар редагує у власному профілі, а пацієнти бачать у списку лікарів;
- профільна картка «Інформація про себе» з фото, спеціальністю, контактами, містами роботи й описом на оглядовій сторінці лікаря;
- цілісна оглядова сторінка профілю лікаря без панелей швидких дій: окремо залишені лише запис пацієнта й редагування профілю;
- публічна головна сторінка з новинами клініки, новинами лікарів і галереєю;
- зміна логотипа та спільного фонового зображення для всіх сторінок адміністратором;
- вибір анімованого пресета поверх фонового фото: літаючі зуби або медичні хрестики;
- завантаження власного зображення для анімованих частинок головної сторінки;
- швидкий рух і обертання анімованих частинок із відбиванням від меж сторінки;
- інтерактивний пресет «Стоматологічне поле» із зубами й брекетами, які відштовхуються від курсора та один від одного;
- створення новин клініки адміністратором і власних новин кожним лікарем.
- перехід на головну сторінку за натисканням на логотип або назву клініки для всіх користувачів.
- рольові кнопки на головній сторінці: кабінет лікаря, панель адміністратора або запис пацієнта на прийом.

Проєкт не містить вигаданих лікарів або пацієнтів. Дані створює адміністратор і реальні користувачі.

## Запуск на Windows

Відкрий PowerShell у папці проєкту та виконай команди по черзі.

1. Активуй віртуальне середовище:

```powershell
.venv\Scripts\Activate.ps1
```

2. Встанови пакети:

```powershell
pip install -r requirements.txt
```

3. Підготуй базу даних:

```powershell
python manage.py migrate
```

4. Створи адміністратора, якщо його ще немає:

```powershell
python manage.py createsuperuser
```

5. Запусти сайт:

```powershell
python manage.py runserver
```

6. Відкрий у браузері `http://127.0.0.1:8000/`.

Зупинити сервер можна комбінацією `Ctrl + C` у PowerShell.

## Google-вхід

1. Створи OAuth Client ID у Google Cloud Console.
2. Додай дозволені callback-адреси:

```text
http://127.0.0.1:8000/accounts/google/login/callback/
http://localhost:8000/accounts/google/login/callback/
```

3. Відкрий Django Admin: `http://127.0.0.1:8000/admin/`.
4. У розділі `Sites` встанови домен `127.0.0.1:8000`.
5. У `Social applications` створи застосунок із провайдером Google.
6. Встав Client ID і Secret key та додай сайт до `Chosen sites`.

## Пацієнт, якого записав лікар

Якщо лікар створив прийом для людини, яка ще не має кабінету:

1. На головній сторінці пацієнт натискає `Вас уже реєстрував лікар?`.
2. Вводить той самий номер телефону, який лікар указав під час запису.
3. Система перевіряє, чи є неприв’язаний запис або картка з цим номером.
4. Пацієнт обов’язково входить через Google.
5. Після Google-входу всі неприв’язані записи й картки з цим номером з’являються в його кабінеті.

Сам номер телефону не відкриває медичні дані. Завершити прив’язування без Google-акаунта неможливо.

Під час створення прийому лікарем номер також перевіряється. Якщо він уже належить зареєстрованому пацієнту, прийом автоматично додається до його кабінету. Якщо акаунта ще немає, але лікар уже створював картку з цим номером, система повторно використовує цю картку замість створення дубля.

## Керування головною сторінкою

Адміністратор відкриває `Панель адміністратора` → `Контент сайту`. Там можна:

- змінити назву, логотип і фон клініки;
- створити, відредагувати, приховати або видалити новини;
- додати, відредагувати, приховати або видалити фотографії галереї;
- редагувати публікації лікарів за потреби.

Лікар відкриває свій кабінет → `Мої новини`. Він може керувати лише власними публікаціями.

## Активний прийом і картка пацієнта

Під час підтвердженого прийому в кабінеті лікаря автоматично з'являється зелений блок `Зараз працюєте з клієнтом`. Час завершення враховує тривалість одного слота та кількість слотів запису.

Кнопка в зеленому блоці відкриває картку поточного пацієнта. Лікар може додати:

- тип медичного запису;
- короткий заголовок;
- детальну інформацію про огляд або лікування;
- рекомендації пацієнту;
- декілька фотографій або медичних знімків одночасно.

Записи типу `Лікування` та `Рекомендації` автоматично відображаються в особистому кабінеті відповідного пацієнта. Внутрішні типи `Нотатка` й `Огляд` бачить тільки лікар.

## Тривалість прийому та обід

Пацієнт не обирає тривалість заявки. Під час підтвердження лікар обирає час відповідно до слота конкретного дня. Наприклад, якщо слот дорівнює `20 хв`, доступна тривалість `20`, `40`, `60` хвилин і так далі. Система перевіряє кінець прийому, наступні записи, обід і робочий час.

Щоб додати обід, лікар відкриває `Мій графік`, обирає день і заповнює:

- `Початок обідньої перерви`;
- `Тривалість обіду, хвилин`.

Обидва поля можна залишити порожніми, якщо обід не потрібен. Час, який перетинається з обідом, автоматично зникає зі списку доступного запису.
